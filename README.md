## Sobre o Projeto

O **EcoAmazônia** é uma plataforma web desenvolvida para monitorar e apresentar informações relacionadas ao **desmatamento da Amazônia**.

O sistema utiliza **Python, Flask, HTML, CSS e JavaScript**, oferecendo uma interface moderna, responsiva e intuitiva.

A aplicação tem como objetivo transformar dados ambientais em informações acessíveis, utilizando **dashboards, gráficos, mapas interativos, indicadores e alertas**.

---

## Objetivo

O projeto tem como objetivo utilizar a tecnologia como ferramenta de apoio à preservação da Amazônia.

A plataforma busca:

- Monitorar informações ambientais.
- Apresentar indicadores de desmatamento.
- Acompanhar focos de incêndio.
- Visualizar regiões monitoradas.
- Identificar áreas de atenção.
- Analisar a evolução dos dados.
- Incentivar a conscientização ambiental.
- Permitir futuras aplicações de inteligência artificial.
