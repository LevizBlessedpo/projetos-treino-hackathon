### 🚀 Maratona Hackathon - Laboratório de Treinamento

Repositório central para armazenamento, versionamento e evolução dos projetos desenvolvidos pela equipe durante a preparação para o Hackathon oficial. 

### 🛠️ Stack Tecnológica Dominada

Nossa equipe está desenvolvendo soluções completas unindo análise de dados, inteligência artificial e interfaces dinâmicas. 

### 🌐 Front-end & Interatividade

* **HTML5 & CSS3:** Arquitetura semântica, estilização responsiva e layouts modernos.
* **JavaScript (Vanilla):** Manipulação assíncrona do DOM, consumo de APIs internas e interatividade.
* **Chart.js:** Renderização de gráficos estatísticos e históricos dinâmicos através de Canvas.
* **Leaflet.js:** Integração de mapas interativos e plotagem de dados geográficos.

### ⚙️ Back-end & Inteligência Artificial

* **Python:** Linguagem base para manipulação, limpeza de dados e estruturação lógica.
* **Flask / FastAPI:** Criação de APIs robustas, rotas assíncronas e middlewares seguros.
* **Groq API:** Integração de modelos de linguagem (LLM) de altíssima velocidade para processamento de linguagem natural em tempo real.

### 📂 Projetos Desenvolvidos (Nosso Laboratório)

### 1. 🌳 EcoAmazônia (Projeto 1)

* **Foco:** Monitoramento histórico e conscientização sobre o desmatamento na Amazônia Legal.
* **Destaque Técnico:** Gráfico PRODES dinâmico integrado via Chart.js, controle de tema personalizado (Modo Escuro) controlado via JavaScript e manipulação refinada de CSS.

### 🚑 2. Emergency IA / AurIA (Projeto 2)

* **Foco:** Triagem médica imediata em tempo real simulando formato de Chatbot.
* **Destaque Técnico:** Arquitetura assíncrona usando fetch() no Front-end para comunicação via protocolo POST (JSON) com a API criada em Python usando FastAPI, gerando respostas dinâmicas baseadas no motor da Groq.

### 🛡️ Boas Práticas de Cibersegurança & Git (CyberSec Hub)

Como parte do treinamento para o ambiente sob pressão do Hackathon, nossa equipe adota padrões rigorosos de segurança no código: 

* **Gerenciamento de Variáveis de Ambiente:** Chaves de API (API Keys) e credenciais sensíveis são estritamente isoladas em arquivos .env.
* **Prevenção contra Vazamentos:** Arquivo .gitignore configurado na raiz para garantir que segredos nunca sejam expostos nos históricos públicos de commits do GitHub.
